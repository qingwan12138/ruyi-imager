<h3>Ruyi Imager</h3>
<p>The system image flashing tool for <a href="https://ruyisdk.org/en/">RuyiSDK</a>.</p>
</div>

Ruyi Imager is a desktop image writer for RISC-V boards supported by the [RuyiSDK ecosystem](https://github.com/ruyisdk/ruyi).

## Highlights

- Find system images for your RISC-V board, or flash a local image.
- Download and flash images in one place, with automatic integrity checks and archive extraction.
- Write to SD cards and USB drives, or flash supported boards directly over USB.
- Available on Windows (x86-64, ARM64), Linux (x86-64, ARM64, RISC-V 64), and macOS (ARM64).

## Download

Builds are published on [GitHub Releases](https://github.com/Glavo/ruyi-imager/releases).
